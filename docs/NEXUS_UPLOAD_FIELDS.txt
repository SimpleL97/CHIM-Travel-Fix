  Name:            CHIM Travel Fix
  Author:          SaurOff
  Version:         1.0.0
  Category:        Bug Fixes
  Adult content:   no

  Brief overview (max 350 characters):
    CHIM AI agents sent somewhere with Travel_To walk to the place they named - in any game language - instead of a random cave. Works around CHIM's broken location lookup; "my house in Whiterun" finds Breezehome. A CHIM server plugin only: no .esp, no scripts, nothing in your save.

  Open the main file's "Advanced" dialog (Files tab) and take the two ids of its API section:
  "Unique Mod ID" -> MOD_ID, "File ID" -> FILE_ID in .github/workflows/release.yml (not the
  numbers in the page address or the download link). From then on a GitHub release is
  uploaded to Nexus as a new version of that file by itself.
